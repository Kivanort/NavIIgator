# 🏛️ NavIIgator — AI-гид по Яндекс Музею

Интерактивный гид-путеводитель по Яндекс Музею с AI-чатом на основе Yandex GPT, персональными маршрутами, викторинами и наградами.

## 🚀 Основные возможности

- **Опросник** — адаптивный квиз из 7 шагов, определяет интересы пользователя и подбирает персональный маршрут
- **AI-гид (чат)** — ответы на вопросы о музее через Yandex GPT API с контекстом 45 экспонатов
- **6 маршрутов** — Яблоко, Программисты, Предприниматели, Геймеры, Новичок, Все экспонаты
- **45 реальных экспонатов** — с описаниями, годами, странами и категориями
- **Викторины** — уникальные вопросы для каждого маршрута (5–8 вопросов)
- **Награды** — аватар, стикеры, значок «Знаток компьютеров» за прохождение викторины
- **Тёмная тема** — переключение с сохранением выбора
- **4 языка** — русский, английский, казахский, сербский
- **Адаптивный дизайн** — работает на мобильных, планшетах и десктопах
- **Прогресс-бар** — анимированный ровер/скутер, движущийся по маршруту

## ⚡ Быстрый старт

### Клонирование

```bash
git clone https://github.com/Kivanort/NavIIgator.git
cd NavIIgator
```

### Установка зависимостей

```bash
npm install
```

### Настройка переменных окружения

Создайте файл `.env.local` в корне проекта:

```env
YC_API_KEY=ваш_токен_Yandex_GPT
```

> Получить API-ключ можно в [Yandex Cloud Console](https://console.cloud.yandex.ru/) → IAM → API-ключи.

### Запуск в режиме разработки

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## 🐳 Запуск через Docker

### Сборка и запуск

```bash
docker compose up -d --build
```

### Проверка статуса

```bash
docker compose ps
docker compose logs -f navigator
```

### Остановка

```bash
docker compose down
```

Приложение будет доступно по адресу `http://localhost:3000`.

> Для работы AI-чата необходим файл `.env.local` с `YC_API_KEY` — Docker Compose автоматически подхватывает его через `env_file`.

## 🚢 Деплой

### VPS + Docker (рекомендуемый)

1. Установите Docker и Docker Compose на сервер
2. Клонируйте репозиторий и создайте `.env.local` с `YC_API_KEY`
3. Запустите:

```bash
docker compose up -d --build
```

4. Настройте reverse proxy (Nginx/Caddy) на порт 3000

### GitHub Actions (CI/CD)

Проект настроен на автоматический деплой через GitHub Actions:

- При пуше в `main` собирается Docker-образ и пушится в GHCR
- Автоматический деплой на сервер через SSH
- Секреты: `YC_API_KEY`, `SERVER_HOST`, `SERVER_USER`, `SERVER_SSH_KEY`
